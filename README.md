# ATELIER NORD

Portfolio concept for a premium architecture and interior design studio.

## Experience

- Cinematic opening sequence and video-led hero
- Six detailed project stories
- Architecture, interior, procurement and delivery services
- Interactive research and material studies
- Studio history, process and leadership team
- Responsive project brief

## Run locally

Open `index.html` directly or serve the folder with any static web server.

## Technology

Vanilla HTML, CSS and JavaScript. No build step is required.
